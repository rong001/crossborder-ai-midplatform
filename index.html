Why Sellers Want This

卖家真正痛点 → AI OS 解法

账号健康失控
Anomaly Agent 7×24 监控绩效指标、ODR、政策风险，异常秒级推送到审批队列，避免封号。
只看 GMV，不见真利润
Finance Agent 归因 FBA 费、佣金、广告、退款、头程，输出 SKU 级真利润与回款预测。
人效瓶颈
多 Agent 自动跑巡检与草稿，人只审高风险门；运营人效可从「盯屏」升级为「审批编排」。
多平台割裂
连接层统一 Amazon / Shopee / TikTok / Lazada / Temu / Walmart，数据层一份经营事实。
广告预算浪费
投放 Agent + ACOS 守卫：超标自动暂停、预算再分配、否定词建议，减少无效花费。
断货与滞销并存
补货 Agent 结合海外仓 lead time 与销量预测生成 PO；仓储 Agent 优化库位与波次。

Design Philosophy

为什么这样设计

许多市场与团队仍在用表格和卖家原生后台。黑盒「一键 Agent 跑完全流程」会制造不信任，也学不到 Day-1 步骤。本套演示刻意做成：引导上手 + 人机协同。

信任 Trust
AI 提出建议与草稿，高风险动作进入审批门；界面清楚展示「等待审批」，而不是静默改价/下单。
本地化 Localization
阈值、话术、科目映射按站点/平台适配；向导要求先准备知识库与规则，而不是一套全球默认值闷头跑。
上手 Onboarding
每个模块顶栏有「操作手册」与「上手向导」（5～7 步清单）。进度存 localStorage，可随时重开，无需销售员代点魔法按钮。
人机门 Human Gates
默认 CTA：按向导下一步 / 查看推荐并确认 / 批准此条。「模拟全自动」收在进阶披露里，仅作架构演示。
给客户演示时请强调：打开任意模块 → 先看操作手册 → 走上手向导勾选知识库与规则 → 对一条 AI 建议点「批准此条」。不要默认演示「一键跑完」。

Getting Started

如何开始

新手可在无人陪同下完成：读手册 → 走向导 → 批准一条推荐。建议从指挥中台开始。

步骤 01

打开指挥中台上手向导

确认业务范围、标记知识库、保存 ODR/ACOS/审批阈值，再载入演示数据。

进入中台向导 →
步骤 02

每个模块都有手册 + 向导

ERP / OMS / WMS / Ads / CS / BI / Finance 顶栏同样提供「操作手册」与「上手向导」，进度按模块分别保存。

步骤 03

体验「推荐 → 人确认」

在建议收件箱点「批准此条」或「查看推荐并确认」。全自动编排仅在「进阶」披露中，需显式展开。
