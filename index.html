Data

平台数据怎么进

官方 OAuth（推荐）

店铺 / 广告 / 邮箱分项授权。跳转平台同意页 → refresh_token。Amazon SP-API、Shopee/TikTok/Lazada/Temu/Walmart OpenAPI。

打开店铺授权中心
CSV / 手工导入

未对接平台用后台导出表头映射。演示支持「使用演示数据」一键载入待审核单与采集箱草稿。

禁止 Cookie

不提供粘贴 Cookie / 填密码进自有库。与官方 OAuth 习惯相反且危险。紫鸟等环境隔离不替代 SP-API。

Design

为什么这样设计

日活在队列，不在大屏

中国卖家打开系统先看待审核 / 未配对 / 缺货 / 留言。所以首屏是密集表 + 状态 Tab + 批量勾选，不是 Agent 画布或玻璃拟态营销墙。

AI = 推荐，不是替代审批

真实 SaaS 是规则 + 异常人工。默认 CTA：查看推荐并确认 / 批准此条。全自动仅在「进阶」披露内。

毛利必须展开平台费项

只显示「收入−采购」会被当成外行。财务模块可勾选佣金、FBA、仓储、广告、退货、头程、汇损、包装。

操作手册 + 上手向导

每个模块顶栏保留。向导对齐行业 onboarding：授权 → 配对 → 仓库 → 物流 → 规则 → 演示数据 → 走通一单 → 配置毛利。
